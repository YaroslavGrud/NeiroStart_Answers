1. Что такое компьютерное зрение?
Ответ: Область ИИ, позволяющая компьютеру "видеть" и интерпретировать изображения и видео

2. Где применяется компьютерное зрение в медицине?
Ответ: Для диагностики заболеваний кожи
Для анализа рентгенов и МРТ
Для распознавания клеток в лабораториях

3. Какую задачу компьютерное зрение решает в автономном транспорте?
Ответ: Обнаружение пешеходов и препятствий

4. Какой термин используется для описания распознавания символов с изображений (например, для перевода текста с вывески)?
Ответ: ocr

5. Для чего в ритейле применяется компьютерное зрение?
Ответ: Для анализа поведения покупателей
