1. Что такое вложенные коллекции?
Ответ: Коллекции, содержащие другие коллекции

2. Какие структуры данных могут использоваться во вложенных коллекциях?
Ответ: Списки
Кортежи
Словари

3. Какие коллекции можно встретить внутри вложенных структур?
Ответ: Списки
Словари
Множества

4. Что произойдёт после выполнения data["a"].append(3), если data = {"a": [1, 2], "b": [3, 4]}?
Ответ: Элемент 3 добавится в список по ключу "a"

5. Какой метод используется для добавления элемента в конец списка?
Ответ: append
