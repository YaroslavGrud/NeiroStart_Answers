1. Какова временная сложность следующего кода?
Ответ: O(n²)

2. В каких случаях временная сложность алгоритма может быть O(n²)?
Ответ: Когда один цикл вложен в другой, оба проходят по n
Когда внешний цикл идёт по n, а внутренний по i

3. Что означает обозначение O(n³) во временной сложности?
Ответ: Время выполнения растёт пропорционально n × n × n

4. Как называется метод оценки количества шагов, необходимых алгоритму в зависимости от размера входных данных?
Ответ: Сложность

5. Какой из следующих алгоритмов будет иметь наименьшую временную сложность?
Ответ: Алгоритм с одним циклом for от 0 до n
