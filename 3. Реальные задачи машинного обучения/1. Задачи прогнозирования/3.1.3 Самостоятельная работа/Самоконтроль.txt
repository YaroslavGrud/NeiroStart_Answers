1. Для чего используется логистическая регрессия?
Ответ: Классификация объектов

2. Какие преимущества есть у логистической регрессии?
Ответ: Быстро обучается
Легко интерпретируется
Подходит для бинарных задач

3. Какая функция используется в логистической регрессии для получения результата от 0 до 1?
Ответ: Сигмоидная

4. Какой метод расширяет логистическую регрессию на многоклассовые задачи?
Ответ: One-vs-Rest

5. Как называется задача, в которой нужно разделить объекты на два класса?
Ответ: бинарная
