1. Для чего нужны обучающие данные, созданные по формуле, например y = 2x + 1?
Ответ: Чтобы обучить модель находить зависимость

2. Почему при обучении используют параметр validation_split?
Ответ: Чтобы протестировать модель на новых данных

3. Какие из следующих утверждений справедливы для процесса обучения нейросети?
Ответ: Модель обучается с каждым примером, постепенно улучшая точность
Количество эпох влияет на итоговую точность модели
Если модель переобучается, нужно проверять её на отложенных данных

4. Как можно проверить, хорошо ли модель обучилась?
Ответ: Посмотреть, уменьшилась ли функция ошибки при обучении
